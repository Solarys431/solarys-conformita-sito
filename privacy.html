Privacy

Ultimo aggiornamento: 28 agosto 2026

Dati raccolti dal sito

Questa landing non contiene account, moduli, newsletter, analytics, pixel pubblicitari o strumenti di profilazione. Non imposta cookie propri e non raccoglie direttamente nomi, indirizzi email o altri dati inseriti dal visitatore.

Hosting GitHub Pages

Il sito è ospitato da GitHub Pages. GitHub dichiara che, quando una pagina viene visitata, l'indirizzo IP del visitatore viene registrato e conservato per finalità di sicurezza. Il titolare di questa landing non riceve né consulta i log grezzi dei visitatori. Per il trattamento svolto dalla piattaforma consulta la GitHub Privacy Statement e la documentazione GitHub Pages.

Cookie e collegamenti esterni

La landing non utilizza cookie di profilazione o tracciatori non tecnici e non richiede quindi un banner di consenso. I collegamenti a GitHub portano a un servizio esterno, regolato dalle condizioni e dall'informativa di GitHub. Per approfondire consulta le FAQ sui cookie del Garante per la protezione dei dati personali.

Aggiornamenti

Questa informativa dovrà essere aggiornata prima di introdurre moduli, analytics, contenuti incorporati da terzi o altre funzionalità che trattino dati personali.
